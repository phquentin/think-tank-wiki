# TODOs

**This page is derived.** Source of truth: the `[TODO]` markers on
individual wiki pages. Regenerated by `/lint`
(see [`AGENTS.md`](../AGENTS.md) §4.6) — **do not hand-edit**. If
you want to add, edit, or close an item, change the marker on its
source page and re-run `/lint`.

Last regenerated: never (template).

Each entry is annotated with the **proposed closing action**:

- `→ /research` — external answer needed.
- `→ /decide` — user choice needed.
- `→ /note` — user already knows the answer; just capture it.
- `→ /ingest` / `→ synthesis` — wiki-side write.
- `→ external` — action that lives outside the wiki.
- `→ multi-step` — sequential combination of the above.

Where multiple pages raise the same task, the entry is clustered
and lists all source pages.

Topic bins below are populated by `/lint` based on what's actually in
the wiki; the set is not fixed (see [`AGENTS.md`](../AGENTS.md) §3.3).
`[[todos]]` always includes a "Wiki maintenance" bin for structural
follow-ups.
